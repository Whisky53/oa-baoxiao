# 差旅费报销自动化（OA 填单）

把铁路电子客票（火车票）PDF 自动填入树根互联 OA 的「差旅费报销单 v2.0」，
免去手工逐字段填写。支持单张报销与批量报销（一次填多张票）。

---

## 1. 项目解决什么问题

日常报销火车票需要在 OA 里手工填写一张 20+ 字段的报销单：
选择公司、票据类型、出差申请关联、申请事由、发票张数、上传发票、报销明细行
（费用类型/出发地/目的地/起止日期/金额/发票币种/发票类型/发票号码）、
项目相关信息、只报账不付款、是否冲销借款、支付对象，最后暂存提交。

本项目把这一整套手工操作自动化：

- **发票信息零人工录入**：从 PDF 内嵌的铁路电子客票 XML 直接读取（比 OCR 更准），
  出发地/目的地/乘车日期/金额/发票号/税额全部自动带出；
- **一张报销单自动完成**：表头、上传发票、出差申请关联、明细行、项目、单选规则、暂存；
- **批量一次报多张**：扫描目录自动去重，每张发票一行明细；
- **新人可安装**：跨 macOS / Windows / Linux，`install.py` 一键装好。

## 2. 主要功能

| 功能 | 说明 | 入口 |
|---|---|---|
| 发票解析 | PDF 嵌入 XML → 结构化乘车信息（车次/站/日期/金额/发票号/税额） | `scripts/rail_invoice_parse.py` |
| OA 会话 | 本机登录态自动提取（macOS Chrome cookie），或浏览器引导登录（全平台） | `scripts/chrome_cookies_to_state.py` / `scripts/login_browser.py` |
| 单张报销 | 填表头 + 上传发票 + 出差申请关联 + 明细行 + 项目 + 5 条规则 + 自动暂存 | `scripts/fill_oa_auto.py` |
| 批量报销 | 扫描目录全部发票 → 去重 → 一张报销单多行明细 | `scripts/fill_oa_batch.py` |
| 一键安装 | 环境检查 → 依赖安装 → 配置向导 → 登录引导 → 会话自检 | `install.py` |
| 项目确认 | 报销前询问用户项目（config 可配，默认空=每次询问） | 对话流程 / `--project` |

自动填写的字段清单：

- 表头：选择公司（树根互联股份有限公司）、票据类型（电子票）、是否有出差申请（是）、
  申请事由（出差客户现场）、报销币种（人民币）、发票张数（附件数）、上传发票、出差申请关联
- 报销明细行（每张票一行）：费用类型（火车/高铁费用）、出发地、目的地、开始/结束日期、
  报销金额、发票币种（人民币）、发票类型（专票）、发票号码、OCR 不含税金额、OCR 税额、项目相关信息
- 后置规则：只报账不付款=否、是否冲销借款=否、支付对象=本人、自动暂存

## 3. 安装方法

要求：Python 3.8+、Chrome 浏览器（脚本自动探测本机 Chrome）。

```bash
# 1) 进入项目目录
cd 差旅报销自动化

# 2) 一键安装（检查环境 → 装依赖 playwright+pypdf → 配置发票目录 → 登录 OA → 自检会话）
python install.py
# 参数: --skip-deps 跳过依赖 / --skip-login 跳过登录 / --check-only 只查环境
```

安装器会自动：
1. 检查 Python 版本、探测 Chrome；
2. 安装 `playwright`、`pypdf`（Chromium 下载失败自动回退本机 Chrome）；
3. 询问发票目录（首次运行确认一次，默认桌面「待使用」，见 config.json）；
4. 引导登录 OA：macOS 优先自动提取 Chrome 已登录会话（无需输密码），
   Windows/Linux 打开浏览器手动登录一次；
5. 无头自检会话有效性，输出安装报告。

可选配置（`config.json`）：

```json
{
  "company": "树根互联股份有限公司",
  "fee_type": "火车/高铁费用",
  "project": null,
  "invoice_dir": null,
  "submit_mode": "manual"
}
```

`project` 为空时，每次报销前会先询问项目。

## 4. 使用方法

**方式 A：对话触发（推荐）**

在 WorkBuddy 对话里说「**火车票报销**」：
1. 助手先确认项目（默认「工业可视化DV」，可改）；
2. 确认后自动执行：扫描发票目录 → 解析去重 → 填表头 → 上传发票 →
   出差申请关联 → 每张发票一行明细（含项目）→ 5 条规则 → 自动暂存；
3. 弹出浏览器窗口供核对（20 分钟），自动暂存后数据在 OA 草稿箱，
   用户检查（补「本月资金计划编号」等）后手动提交。

**方式 B：命令行**

```bash
# 批量报销（扫描发票目录全部 PDF，去重后一张单多行）
python scripts/fill_oa_batch.py --project "工业可视化DV"

# 单张报销
python scripts/fill_oa_auto.py "/路径/电子发票-xxx.pdf" --project "工业可视化DV"

# 参数
#   --project "项目名"   指定项目（不传则读 config.json 的 project）
#   --trip "关键字"      指定关联的出差申请（不传选第一条）
#   --headless           无头模式（测试用，不弹窗）
#   --no-save            填完不自动暂存
#   --no-save 之外的默认：填完自动点「暂存」
```

发票来源两种都支持：
- **固定目录**：发票 PDF 放进 `config.json` 的 `invoice_dir`（默认桌面/待使用），批量扫描；
- **直接发文件**：把发票 PDF 路径传给 `fill_oa_auto.py`，单张报销。

## 5. 输入输出示例

**输入：一张铁路电子客票 PDF**

```
/路径/电子发票-示例.pdf
```

解析结果（`scripts/rail_invoice_parse.py` 输出）：

```
发票号码: [发票号示例]
乘车人:   [用户]
出发站:   贵阳北
到达站:   广州南
车次:     [车次示例]
乘车日期: 2026-03-15
座位等级: 二等座
票价(含税): 376.00
不含税金额: 344.95
税额:      31.05
购买方:   树根互联股份有限公司
```

**批量输入（一次报销多张）：** 发票目录内多张 PDF，脚本自动按发票号去重，
每张一行明细（示例 8 张 → 8 行）。

**输出：填好的 OA 差旅费报销单（自动暂存到草稿箱）**

| 区块 | 内容 |
|---|---|
| 表头 | 公司=树根互联、票据类型=电子票、出差申请=是、申请事由=出差客户现场、币种=人民币、发票张数=8 |
| 附件 | 8 张发票 PDF 已上传 |
| 明细行 | 行1: 火车/高铁费用 亳州南→阜阳西 2026-04-03 50.00元；行2: …（每张票一行） |
| 项目 | 工业可视化DV（编码 800094 / CODE公司 A000 自动带出） |
| 规则 | 只报账不付款=否、是否冲销借款=否、支付对象=本人 |
| 收尾 | 自动点「暂存」，数据进入 OA 草稿箱；用户检查补「本月资金计划编号」后手动提交 |

## 目录结构

```
差旅报销自动化/
├── install.py                    # 一键安装器（新人入口）
├── config.json                   # 配置（公司/费用类型/项目/发票目录）
├── data/oa_state.json            # OA 登录会话（运行时生成）
└── scripts/
    ├── rail_invoice_parse.py     # 发票 PDF → 结构化信息
    ├── chrome_cookies_to_state.py# (macOS) 提取本机 Chrome 的 OA 会话
    ├── login_browser.py          # (全平台) 浏览器引导登录保存会话
    ├── fill_oa_auto.py           # 单张自动填表（含项目/5条规则/暂存）
    └── fill_oa_batch.py          # 批量自动填表（推荐）
```

> 技能包（可移植版）位于 `~/.workbuddy/skills/oa-cha-lv-baoxiao/`，
> 新电脑拷贝后运行 `python install.py` 即可使用，详情见该目录 README.md。

## 已知限制

- 仅支持**铁路电子客票 PDF**（含嵌入 XML）；其他类型发票需扩展解析；
- 「本月资金计划编号」的"选择"弹窗自动化未攻破，需用户在草稿箱检查时手动补；
- 出差申请关联默认选第一条，跨多个出差周期的票建议分开报；
- 发票类型固定"专票"。
